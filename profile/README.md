## 🚀 Who We Are

**PotenFYR Studios** is a creative hub for game development, hosting infrastructure, automation tools, and community-driven projects. From Minecraft plugins and Fabric frameworks to Pterodactyl/Pelican eggs and API security: we build modular, performant, production-ready software in the open.
