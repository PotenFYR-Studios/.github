## 🚀 Who We Are

**PotenFYR Studios** is a creative hub for game development, hosting infrastructure, automation tools, and community-driven projects. From Minecraft plugins and Fabric frameworks to Pterodactyl/Pelican eggs and API security: we build modular, performant, production-ready software in the open.

### 🔍 Project Highlights

<details open>
<summary><b>Tap to explore our flagship projects</b></summary>

### 🥚 Egg Ecosystem: *One egg. Every panel.*
- **[Minecraft-Eggs](https://github.com/PotenFYR-Studios/Minecraft-Eggs)**: Universal Minecraft egg for Vanilla, Paper, Purpur, Fabric, Forge, NeoForge, Velocity, Bedrock & 18+ server types
- **[Database-Eggs](https://github.com/PotenFYR-Studios/Database-Eggs)**: Production-ready multi-database eggs, every version, every panel
- **[Prog-Language-Eggs](https://github.com/PotenFYR-Studios/Prog-Language-Eggs)**: Run 50+ programming languages inside your container

### 🧩 Minecraft Tooling
- **[AuthCore](https://github.com/PotenFYR-Studios/AuthCore)**: Lightweight server-side authentication for Fabric servers · [Modrinth](https://modrinth.com/mod/authcore)
- **[Statfyr](https://github.com/PotenFYR-Studios/statfyr)**: Blazing-fast REST API plugin exposing real-time player statistics · [Modrinth](https://modrinth.com/plugin/statfyr)
- **[ojaj](https://github.com/PotenFYR-Studios/ojaj)**: *OneJumpAllJump*. a chaotic Spigot plugin where a single jump launches the entire server 🚀
- **[EchoingDeaths](https://github.com/PotenFYR-Studios/EchoingDeaths)**: Immersive death-based curses that echo to nearby players

### 🛍️ Commerce, Bots & Security
- **[.web](https://github.com/PotenFYR-Studios/.web)**: Our official website
- **Jericho Discord Bot**: Fast, customizable community management & entertainment · [Invite](https://top.gg/bot/1470079725106888817)
- **[APICordon](https://github.com/PotenFYR-Studios/APICordon)**: GitHub-native API security layer that turns findings into precise PR feedback
